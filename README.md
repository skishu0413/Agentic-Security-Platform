# Agentic AI Security Platform

This project provides a baseline agentic AI security platform for evaluating source code generated by LLMs across multiple providers including OpenAI, Claude, and Ollama.

## Features
- Static review of risky code patterns such as command injection and dynamic execution.
- Provider status reporting for OpenAI, Claude, and Ollama.
- JSON report export for downstream automation.
- Benchmark metadata showing improved performance targets for simple and large tasks.

## Quick start
```bash
cd /Users/surajkhadka/Desktop/Projects/Agentic-ai project
python3 -m pytest -q
python3 agentic_security_platform.py example.py --output report.json
```

## Architecture highlights
- Multi-provider evaluation layer for LLM-generated code.
- Security analysis engine focused on MITRE CWE coverage.
- MLOps-friendly export and reporting interfaces for deployment workflows.

## Security tooling hooks
The platform now includes lightweight wrappers for Bandit and CodeQL so it can optionally merge results from those tools into the JSON report when they are available on the host.

## Deployment notes
For a VPS or OpenStack deployment:
1. Build the container with Docker.
2. Deploy the image to your VM or container host.
3. Expose port 8000 behind a reverse proxy such as Nginx.
4. Store reports on persistent storage for auditability.

## CI and deployment workflow
- GitHub Actions runs the test suite and a smoke CLI run on push and pull request.
- The included deploy script builds and runs the service in Docker for quick VPS or OpenStack deployment.
- The startup script launches either the CLI or the FastAPI service, depending on the arguments provided.

## Web Dashboard
The platform includes a professional, real-time security dashboard accessible at `http://localhost:8000` when the API service is running.

### Dashboard Features
- **Risk Summary**: Visual risk score and severity breakdown
- **Findings View**: Detailed list of security issues by severity and CWE
- **Provider Status**: Real-time status of OpenAI, Claude, and Ollama integrations
- **Interactive Scanning**: Run security scans directly from the dashboard
- **CWE Coverage**: Display of MITRE CWE classifications for findings
- **Responsive Design**: Works on desktop, tablet, and mobile devices
